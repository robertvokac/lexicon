Roadmap & TODO

Lexicon is young and actively developed. This page tracks where it is heading — a great place to look if you want to contribute.

Recently shipped

  • Item table supports sorting by clicking column headers.
  • New item prefills the title from the current search text — search-to-create in one motion.

Roadmap

📤 Export to CSV / JSON

Structured exports of groups and items, so data can flow into spreadsheets, scripts, and other tools.

🌐 Export to static HTML

Publish a whole lexicon as a browsable static website — sharing your knowledge base without sharing the app.

🖧 HTTP server

A built-in server to browse your lexicon from other devices on the local network.

🔎 Better search ranking

Exact matches should surface first; ranking improvements are planned for the search pipeline.

🧱 More unique indexes

Additional database constraints to guarantee consistency as the schema grows.

🕸️ Graph visualization

A visual view of the item relationship graph — the natural payoff of typed links.

Working TODO list

The current TODO.md focuses on polish and future product features. Groups, Items, Types, Fields, typed Values, Links, multi-field search, pinned filters, Markdown editing, and themes are already implemented.

UI polish

  • Improve table column density and wrapping for long Tags, Aliases, and Flags.
  • Review resizing between the item table, content preview, and links area.
  • Add keyboard shortcuts and undo/redo across item edits.

Product features

  • Improve search ranking so exact title matches appear first.
  • Export and import Items and Groups in a documented format.
  • Add an optional graph view of Item relationships.
💡

Want one of these? Pick an item, open an issue to claim it, and see Contributing for the workflow. Small, focused pull requests are the easiest to review and merge.
