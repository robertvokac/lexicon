Board

The Board is one shared Markdown document for information that should stay visible without becoming a collection of separate items — a dashboard, current priorities, a reading list, or whatever belongs on your front wall.

One shared document

There is exactly one Board for the whole dictionary. It has no title, group, type, fields or other item metadata. Open it from any client and you see the same content; save it in one client and the next client loads that change.

The Board starts empty. Markdown gives it structure: headings, emphasis, lists, quotes, links, code and tables all render into a clean reading view.

💡

Board or item? Use the Board for one living overview. Use an item when the note needs its own title, metadata, search result, relationships or review schedule.

Open the Board

ClientHow to open it
DesktopThe Board button to the right of Inbox, or File → Board...
Web clientThe Board button beside Inbox above the item table; on a narrow screen it is in ⋮ More actions
AndroidBoard in the navigation drawer

Read and edit

  1. Opening Board first shows the rendered document. An empty Board says so instead of showing a blank screen.
  2. Choose Edit. The editor uses the same Markdown experience as the Content tab of an item, including the formatting toolbar and source/preview views.
  3. Choose Save to publish the new version. Cancel or go back to leave the stored Board unchanged; Android warns before discarding unsaved text.

Because it is a single document, headings make a useful permanent outline. A small example:

# Board

## Now
- Finish the release notes
- Review the database migration

## Later
1. Clean up old Inbox items
2. Plan the next learning topic

Concurrent edits and backup

Every saved Board has a revision. If another client saves after you opened the editor, your older save is refused instead of silently overwriting the newer text. Reload to take the newer version, keep editing, or deliberately overwrite it where the client offers that choice.

The Board is stored inside lexicon.db. A full database backup includes it, and portable export format version 4 carries it too. Import fills an empty Board, but keeps a different Board that is already in use and reports a warning — it never replaces existing Board text silently.
