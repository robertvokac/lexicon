Board

Boards are named shared Markdown documents for information that should stay visible without becoming separate dictionary items — dashboards, current priorities, reading lists, or whatever belongs on your front wall.

Named shared documents

A dictionary can contain any number of Boards. Each has a unique name but no group, type, fields or other item metadata. A new dictionary starts with an empty Board named Main; create, rename or delete additional Boards in any client, while the final Board is kept.

Open a Board from any client and you see the same content; save it in one client and the next client loads that change. Markdown gives every Board structure: headings, emphasis, lists, quotes, links, code and tables all render into a clean reading view.

💡

Board or item? Use Boards for living overviews. Use an item when the note needs item metadata, a search result, relationships or a review schedule.

Open the Board

ClientHow to open it
DesktopThe Boards button to the right of Inbox, or File → Boards...
Web clientThe Boards button beside Inbox above the item table; on a narrow screen it is in ⋮ More actions
AndroidBoards in the navigation drawer

Read and edit

  1. Opening Board shows the available names. Choose one, or create, rename or delete a Board. An empty Board says so instead of showing a blank screen.
  2. Choose Edit. The editor uses the same Markdown experience as the Content tab of an item, including the formatting toolbar and source/preview views.
  3. Choose Save to publish the new version. Cancel or go back to leave the stored Board unchanged; Android warns before discarding unsaved text.

Within each document, headings make a useful permanent outline. A small example:

# Board

## Now
- Finish the release notes
- Review the database migration

## Later
1. Clean up old Inbox items
2. Plan the next learning topic

Concurrent edits and backup

Every saved Board has a revision. If another client saves after you opened the editor, your older save is refused instead of silently overwriting the newer text. Reload to take the newer version, keep editing, or deliberately overwrite it where the client offers that choice.

Boards are stored inside lexicon.db. A full database backup includes all of them, and portable export format version 7 carries their names and content. Import matches Boards by name, creates missing ones and fills empty ones, but keeps different existing content and reports a warning — it never replaces Board text silently.
