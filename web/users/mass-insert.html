Mass Insert

Create a whole set of items in one worksheet instead of opening the full editor again and again. Mass Insert carries one required Group, one optional Type and a safe local draft until every row has been accepted.

Choose Group and Type

Open Manage → Mass Insert... in the desktop or web client. First choose the Group shared by every row in this batch. Group is required. Type is optional and lists the global Types plus those available in the selected Group.

💡

Use one worksheet per shape. If the next items belong to another Group or need another Type, finish this worksheet and open a new one. This keeps every row predictable.

Fill the worksheet

The first column is always Title. The remaining standard columns cover the same item attributes you use most often:

ColumnHow to fill it
TitleRequired for every non-empty row.
DisambiguationAn optional qualifier for otherwise identical titles.
Aliases, Tags, FlagsComma-separated lists; duplicates and surrounding spaces are cleaned up.
Status, Understanding, PinnedSelect the same state values used by the normal item editor.
ContentMarkdown source for the item.
Propertieskey=value entries separated by semicolons or new lines.

Choose Add row whenever you need another item. Each row has its own Remove action, and completely empty rows are ignored. Choose Insert items when the worksheet is ready.

Type value columns

When you selected a Type, the worksheet appends one column for every field of that Type, in field position order. Boolean values appear as Not set / Yes / No, enums use their configured options, and numbers, dates, times, timestamps and text receive appropriate editors. Leaving a value blank leaves that field unset.

Without a Type there are no value columns, only Title and the standard item attributes. Every inserted item receives exactly the Group and optional Type shown above the worksheet.

Draft recovery and partial failures

Every edit is backed up locally as you work. The desktop client keeps the worksheet in its application settings; the web client keeps it in this browser, separated by signed-in user and server. Closing Mass Insert, closing the tab or cancelling the resume prompt does not erase it. The next time you open Mass Insert, choose Resume, Start over or Cancel.

Insertion proceeds row by row. As soon as a row is accepted by the database or server, it is removed from the draft. If a later row fails validation or conflicts with an existing item, the successful items stay inserted and the worksheet keeps only the rows still waiting. Fix the reported row and try again.

🛟

Nothing is discarded implicitly. Use Discard draft and confirm only when you deliberately want to erase all unfinished rows. Completing the whole batch clears the draft automatically.
