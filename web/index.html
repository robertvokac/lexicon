A desktop knowledge dictionary for structured learning and technical note-taking — groups, items, rich metadata, and typed links between concepts.

Why Lexicon?

Your knowledge deserves more than a flat pile of notes. Lexicon organizes what you learn into a structured, searchable, interlinked dictionary stored locally on your computer.

🗄️

Local-first storage

Structured data lives in a local SQLite file; optional attachments live in the adjacent blobs directory. No cloud or account is needed.

🗺️

Groups and items

Group items into top-level groups such as C++, Databases, or Networking, with full create/edit/delete support.

🏷️

Rich metadata

Every item carries aliases, tags, flags, a status, an understanding level, and a pinned state — so you always know where you stand.

🔗

Typed relationships

Connect concepts with links and backlinks typed as Is A, Part Of, Depends On, Related, and more — building a real concept graph.

✍️

Markdown editor

Write item content in Markdown with a formatting toolbar and a live rendered preview, powered by the md4qt parser.

🔎

Fast search & filters

Search across titles, disambiguations, aliases, tags, and flags. Combine filters for group, type, typed field values, tag, flag, status, understanding, and pinned.

📄

Built for large datasets

Pagination controls and sortable columns keep even very large lexicons fast and easy to browse.

📊

Global overviews

Read-only overviews of all tags, flags, and aliases with usage counts help you keep your vocabulary consistent.

🌗

Light and dark mode

Switch themes from the View menu — your preference is remembered between sessions. This website has it too, try the moon button above.

Up and running in a minute

Lexicon builds from source with CMake and Qt 6. On Debian or Ubuntu it takes three commands:

sudo apt install -y build-essential cmake qt6-base-dev libqt6sql6-sqlite
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build --target Lexicon -j
./build/Lexicon
